# LAS 430 — Teaching portfolio

Static, public-facing review of LAS 430 course exported from Canvas.

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `las430-teaching-portfolio`.
2. Upload **the contents of this folder** to the repository root.
3. In repository Settings → Pages, select **Deploy from a branch**, branch `main`, directory `/ (root)`.
4. The site will appear at `https://YOUR-USERNAME.github.io/las430-teaching-portfolio/`.

## Editorial safeguards
- No learner-specific feedback files or student records are included.
- Third-party PDF/PPT/DOCX attachments are excluded; only course structure and authored Canvas page/prompt text are carried over.
- Canvas-only links are flagged with an explanatory note.
- Inspect course text prior to publishing; remove any unintentional personal information or instructor-only details.
- This site is a course *review portfolio*, not a functioning LMS; discussions, grading, submissions, and Canvas authentication are not implemented.

## Link preservation update
Original hyperlinks, URLs, linked file references, and embedded iframe elements from the revised IMSCC are retained in published artifact pages. Some Canvas-authenticated and `$IMS-CC-FILEBASE$` attachment references may not resolve on GitHub Pages; they have deliberately been left visible for review and replacement. No student feedback attachments or third-party binary reading files were distributed. Verify public suitability and copyright before publishing.
